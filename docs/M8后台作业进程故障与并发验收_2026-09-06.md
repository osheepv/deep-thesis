# M8 后台作业进程故障与并发验收（2026-09-06）

## 范围与结论

使用临时 SQLite 数据库及独立测试子进程，验证 JobWorker 在进程强制终止、租约到期、并发领取和本地连接中断后的行为。测试直接使用项目 JobRegistry、JobWorker 和 JobRuntime，不调用收费模型，不修改主机网络设置。

这次完成的是本机作业层故障验证。没有在正式部署环境关闭网络，也没有证明跨存储业务写入具备 exactly-once 保证。生产部署、供应商请求在途断开和论文阶段人工回退仍保留为后续验收项。

## 已复现与修复

心跳、取消和人工重试原先在读取状态后无条件更新。同一数据库的另一个连接若在两步之间完成任务或领取重试任务，旧请求会续租已结束作业、把成功态改成取消请求态，或清空新 Worker 的租约。

现在使用带状态条件的 SQL 更新：

- 心跳同时校验 owner、运行状态和未到期租约；未命中时明确返回状态冲突。
- 取消仅更新待执行、执行中和取消请求状态，并根据写入时的当前状态决定取消行为。
- 人工重试校验失败/取消状态和读取版本；另一请求已经改变任务时拒绝覆盖。
- 完成/失败登记拒绝过期租约；模型调用前检查当前执行权。
- Worker 轮询捕获租约/状态冲突，保留新 owner 的结果并继续领取下一项任务。

## 验证矩阵

| 场景 | 操作 | 断言 |
| --- | --- | --- |
| 运行中强杀 | spawn 子进程进入处理器，登记测试用量后由父进程 kill | 租约未到期不可领取；自然等待10秒租约到期后，同一 job 以第2次尝试恢复；用量保留；重新打开数据库可读到结果 |
| 多进程领取 | 3个子进程从同一 SQLite 同时领取24个作业 | 每项成功、attempt=1、结果对应各自 job_id |
| 本地连接中断 | 关闭 socket 对端，在实际 recv 时收到 EOF | 作业失败；人工重试后成功；历史用量不清零 |
| 心跳竞态 | 两个连接在读取与写入间插入作业完成 | 心跳被拒绝，成功态与已清空租约保持正确 |
| 取消竞态 | 读取运行态后由另一连接先完成 | 取消不覆盖成功态 |
| 人工重试竞态 | 第二个请求完成重试并由新 owner 领取 | 旧重试请求被拒绝，新 owner 不被清空 |
| 租约转移后轮询 | 原处理器返回前由另一连接接管并完成 | 原结果不覆盖新结果，Worker继续执行下一项 |
| 过期执行权 | 确定性设置过期租约 | 心跳、结果完成和下一次模型调用均被拒绝 |

最后一个测试通过修改测试数据库的时间戳精确模拟过期；强杀测试使用真实时间等待，无时间戳注入。并发竞态测试使用同步事件控制交错顺序；多进程测试使用真实 spawn 进程和共享数据库。
