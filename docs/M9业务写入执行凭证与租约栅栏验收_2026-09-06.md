# M9 业务写入执行凭证与租约栅栏验收（2026-09-06）

## 目标

解决后台 Worker 在租约过期、同名 Worker 重新领取任务后，旧执行上下文迟到写入任务记录、FSM、章节检查点、分节草稿和产物账本的问题。

## 实现

- `JobRun` 增加 `lease_token` 执行凭证；同一 `worker_id` 重新领取任务时生成新凭证。
- `heartbeat`、`complete`、`fail`、取消检查和模型调用前检查均校验当前租约与凭证。
- 增加 `write_fence` / `job_write_fence`：业务写入前在作业库执行原子租约校验，校验失败或取消时回滚，避免旧执行上下文提交。
- 任务记录、FSM 状态与验收门、章节分节、产物版本与自动验收，以及删除清理入口统一接入写栅栏。
- 旧 `t_job_run` 数据库无 `lease_token` 列时自动迁移，既有任务继续可读，新领取任务获得新凭证。
- InMemory 任务/FSM 读取返回深拷贝，避免调用方持有可变对象绕过写入口修改内存状态。

## 验收覆盖

- 旧租约迟到覆盖任务记录（内存、磁盘）。
- 旧租约迟到写入 FSM（内存、SQLAlchemy）。
- 旧租约迟到创建/提交章节分节与产物被拒绝。
- 写栅栏持有期间接管等待，写入完成后新租约继续工作。
- 栅栏异常、取消、跨任务写入均回滚或拒绝。
- 同名 Worker 的旧凭证无法续租、完成或失败新作业。
- 旧数据库自动补列并兼容重启。
- 环6实际章节检查点回调的迟到写入被拒绝，不能替换新执行结果。
