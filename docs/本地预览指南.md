# Deep Thesis 本地源码预览包

这是受控试用包，包含后端源码、完整前端和启动脚本，不是免安装桌面版，也不是公网部署方案。需要 Python 3.12 或以上；首次安装依赖需联网，模型写作需用户自己的 DeepSeek 接口配置。

## 首次安装

解压 ZIP，进入其中的 `deep-thesis` 目录，在 PowerShell 执行：

```powershell
py -3.13 -m venv .venv
.venv/Scripts/python.exe -m pip install --index-url https://pypi.org/simple ./backend
```

如果仅安装了 Python 3.12，将 `-3.13` 改为 `-3.12`。依赖包含本地检索模型相关组件，首次安装可能较慢。不要把真实密钥填写进示例文件后公开分享。

## 启动

选择一个独立于解压包的绝对数据目录，之后每次都使用同一路径：

```powershell
.venv/Scripts/python.exe scripts/run_preview.py --data-dir 'D:\DeepThesisData'
```

启动器运行本机 API 和完整前端，显示可点击地址；默认访问 `http://127.0.0.1:8787`。只监听本机，不自动开放防火墙或安装系统服务。请保持终端打开，在界面按现有模型设置流程配置 DeepSeek。模型不可用时会明确报错，预览入口不默认开启假数据回退。

端口被占用会明确提示，可加 `--api-port 8001 --ui-port 8788`。访问启动器输出的完整链接，其中包含对应 API 地址。启动失败查看终端错误；缺少依赖时重新核对安装步骤。

不要混用自定义数据库/附件路径环境变量；本入口会拒绝这些覆盖项，以便确保数据全部进入指定目录。需要复杂部署时使用独立 Worker 部署方案。

## 停止与继续

优先等待当前作业结束，再按 Ctrl+C。启动器停止自身服务，但不删除数据；在 Windows 上结束进程不保证等待当前模型调用完成。再次使用相同数据目录启动后，按恢复摘要接续；强制退出时可能需要等待作业租约到期。

论文数据不要放进解压目录，以免升级替换程序时混淆。升级前先停服务并做备份，保留旧包与旧配置；本预览不自动升级或迁移数据库。若使用旧项目数据，先核对备份和存储迁移指南，不能直接指向一个不完整目录并当作已迁移。

## 分发校验

`preview-manifest.json` 记录源码提交及每个打包文件的 SHA-256。构建器只读取 Git 已提交文件，不打包本地未提交配置、数据库或额外报告；若选中路径中出现已跟踪的运行数据库或 `.env`，会拒绝构建。清单用于完整性检查，不是数字签名。

当前功能与质量边界以项目 README 和路线图为准。请用非敏感材料开始试用，并由作者评审各阶段产物。
