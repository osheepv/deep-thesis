# M11 独立 Worker 与共享存储验收

日期：2026-09-08

## 本次交付

- 提供 `python -m application.worker` 和安装包命令 `deep-thesis-worker`，支持前台轮询、单次执行、启动对账检查和自定义 Worker 名称。
- 抽出 API / Worker 共用的业务装配；独立 Worker 不导入 `application.main`，不创建 FastAPI 应用或监听 HTTP 端口。
- 新增可选 `THESIS_DATA_DIR`，在业务模块加载前确定数据路径；分离模式拒绝内存仓储、相对存储路径和不可用 FSM 数据库。
- 新增 SQLite 模板/生成文件登记仓储，API 和 Worker 共享记录；保留归属校验、模板软删除和重启读取能力。未启用统一目录的现有开发装配保持兼容。
- SIGINT / SIGTERM 停止后续领取，当前作业继续完成；异常启动对账阻止领取作业。

## 验收证据

`tests/test_standalone_worker.py` 的集成用例在隔离临时目录内启动 API 测试进程，经真实路由入队；从另一个工作目录启动独立 CLI 进程，执行离线环1作业。API 不启动内置 Worker，仍能读到完成状态与待审批产物；同幂等键不会新建作业。再次启动进程验证任务、作业和启动对账状态。

该用例还使用另一个独立进程调用正式渲染器生成真实 DOCX，正在运行的 API 成功通过下载路由读取文件，重启后仍可读取登记。此项验证跨进程渲染/登记/下载，不替代完整十环 DOCX 作业的发布环境验收。

其他测试覆盖四种非持久配置拒绝、不可用 FSM 不降级、孤立作业启动拒绝且 attempt 不变、前台停机不领取下一作业、CLI 实际 SIGTERM 处理及处理器恢复、模板/文件登记重启保留与跨用户归属校验。

## 验证结果

- 本阶段新增测试：10 项；首轮定向回归全部通过，之后补充的真实 DOCX 跨进程下载集成用例单独通过。
- 原有作业与启动对账回归：16 项通过。
- 离线学术质量规则评测：31/31 通过，无真实模型调用。
- 安装包构建成功；独立安装目录中的模块入口 `--check` 返回 `CONSISTENT`，控制台命令 `--once` 返回 `IDLE` 并以 0 退出。
- 全量回归：415 项通过，236.10 秒；1 个既有 FastAPI/httpx 弃用警告。

安装包首次非隔离构建因本机测试环境缺少 setuptools 失败；随后使用官方 PyPI 提供临时隔离构建依赖，构建及独立安装验证成功。未变更用户运行环境配置。
