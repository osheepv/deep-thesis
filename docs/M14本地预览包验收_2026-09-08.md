# M14 本地源码预览包验收

新增 `scripts/build_preview.py`，从 Git HEAD 的已提交文件构建 ZIP，包含后端源码、完整前端、许可证、主要操作指南及 SHA-256 清单。未提交文件不进入包，选中范围内已跟踪的运行数据库或真实 `.env` 会阻断构建。

新增 `scripts/run_preview.py`，一个命令启动本机 Uvicorn API 与静态界面，API 内置 Worker。检查端口、依赖和数据目录，拒绝混合存储覆盖配置；任一服务退出会停止另一服务。Ctrl+C 退出后保留持久化数据，不承诺中断时的模型调用已经完成。

本地 `pytest tests/test_preview_bundle.py -q --tb=short`：3 项通过，23.56 秒。覆盖按提交打包/摘要匹配/运行数据排除、已跟踪数据库阻断，以及真实启动 API 与界面、静态脚本可取、创建持久任务、模拟 Ctrl+C 后两个监听端口关闭。测试未调用真实模型。

首次测试的 stdin 控制线程在本机导致启动阻塞，已改为定时进程内 Ctrl+C，实际启动与清理测试通过。

该包需要 Python 3.12+ 和首次联网安装依赖。现有测试环境已具备依赖，本次不宣称验证了全新 Windows 上的完整依赖安装；免安装打包、自动升级、代码签名和公网部署仍是后续工作。未创建 GitHub Release。

构建示例：`python scripts/build_preview.py --output ABSOLUTE_ZIP_PATH`。输出必须不存在。为确保提交可追溯，先提交需要打包的变更，再运行构建；不要将真实论文或密钥加入 Git。
